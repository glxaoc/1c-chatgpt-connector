# Несколько баз и SSH

До трёх баз (`ODATA_URL`, `ODATA_URL_2`, `ODATA_URL_3`, имена `BASE_NAME*`), параметр `base` у инструментов.
Сервер-посредник по SSH (`SSH_HOST`, `SSH_USER`, `SSH_PASSWORD` или `SSH_KEY_PATH`), если 1С пускает только
белый список IP.

## Driving it

Не в smoke. Покрыто `tests/suite.mjs` (2 базы, 3-я без имени, неверный пароль второй; SSH: адреса в разном
виде, неверный пароль, только ключ, сервер не слушает, 1С недоступна с сервера), заглушка `tests/mockssh2.mjs`.
Запуск: `verify.sh tests` или в составе `all`.

## Gotchas

- Каждая SSH-проверка около 2,6 с: это основная часть времени тестов.
- Установщик Windows в автоматическом режиме умеет `-SshHost`, но в smoke установка идёт без SSH.
