# Карта проверки 1С-коннектора для ChatGPT (Codex)

Что человек делает с коннектором и как это доказать на стенде `verify-1c-chatgpt`. Перед прогоном прочитать
этот индекс, затем файл нужной функции.

## Базовые условия

- `npm ci` выполнен, `verify.sh doctor` даёт `DOCTOR OK`.
- 1С подложная: `startMock()` в `smoke.mjs` (база `/ВерифБаза/odata/standard.odata`, логин `verify.user`,
  пароль фиктивный) или `tests/mock1c2.mjs` для тестов репо.
- Окружение сервера собирается с нуля (`baseEnv`), домашние папки временные.

## Соглашения

- Инструменты вызывать через MCP-клиент SDK (`withMcp`), как это делает Codex, а не импортом функций.
- Пароли, логины, адреса только из стенда. Настоящие базы 1С, серверы клиентов и чаты не трогать.
- Проверка смысла ответа (есть нужное слово, число, название) плюс проверка побочного эффекта
  (журнал запросов к 1С, файл настроек, `config.toml`).

## Функции

- [Проверка связи](./check-connection.md): `check_connection`, самопроверка установщика. **В smoke.**
- [Чтение данных](./read-data.md): `list_objects`, `describe_object`, `query`, `count`. **В smoke.**
- [Установка Windows](./install-windows.md): ZIP, `install.ps1`, `config.toml`, удаление. **В smoke.**
- [Установка Mac](./install-mac.md): ZIP, `install-mac.sh`, `check.mjs`. **В smoke (в Git Bash).**
- [Справка автора](./author.md): `what_else`, `contact_author`, подсказка про персональные данные. **Частично.**
- [Несколько баз и SSH](./bases-ssh.md): параметр `base`, сервер-посредник. **Только в tests/suite.mjs.**
