# Что смотреть ревьюеру в 1С-коннекторе для ChatGPT (Codex)

Файл читается critic и /code-review первым. Источник правды о поведении: README.md, `tests/suite.mjs` и
`.claude/skills/verify-1c-chatgpt/SKILL.md`.

Формат пункта: триггер в диффе, что проверить, откуда.

1. **Только чтение.** Триггер: `method:` в `server/index.js`, новые `http.request`, `fetch`, `$batch`, `PATCH`, `POST`, `DELETE`, слова «записать», «провести», «создать» в описаниях инструментов. Что проверить: к 1С уходят только GET; инструмента на запись нет; в instructions и README по-прежнему «Коннектор только читает». Откуда: README («Коннектор только читает данные»), `installer/install.ps1` (строка о только чтении), smoke `mcp` («подложная 1С: все GET», «код сервера: HTTP-метод только GET»).

2. **Набор инструментов и readOnlyHint.** Триггер: `server.registerTool(`, `annotations`, переименование инструмента. Что проверить: у каждого инструмента `annotations: { readOnlyHint: true }`; имя латиницей до 64 символов; новый или удалённый инструмент осознанно отражён в `EXPECTED_TOOLS` в `smoke.mjs`, в instructions и README. Без `readOnlyHint` приложение начнёт спрашивать подтверждение на каждый запрос (`default_tools_approval_mode = "writes"` в `config.toml`). Откуда: README (раздел установки: «Все инструменты помечены только чтение…»), `installer/install.ps1` (`Update-Config`), `mac/install-mac.sh`.

3. **Чистый stdout.** Триггер: `console.log`, `process.stdout.write` в `server/index.js`, `app/launcher.js`, `app/settings.js`. Что проверить: в stdout пишет только MCP-транспорт, все сообщения и ошибки идут в stderr (`log()`, `console.error`); `launcher.js` запускает сервер с `stdio: "inherit"` и ничего не печатает сам. Иначе Codex теряет протокол. Откуда: шапка `app/launcher.js`, smoke `mcp` («stdio: в stdout только JSON-RPC»).

4. **Пароли и адреса 1С не утекают.** Триггер: правки `contact_author`, `authorDm`, `fail(`, `log(`, текстов ошибок, `check_connection`, `selftest.js`, `check.mjs`. Что проверить: пароль 1С и SSH не попадает в ответы, stderr-лог и ссылку t.me; `contact_author` не кладёт логин, пароль и адрес 1С ни в текст, ни в URL; instructions по-прежнему запрещают просить пароли. Откуда: описание `contact_author` в `server/index.js`, `tests/suite.mjs` («обращение к автору: нет пароля, логина и адреса 1С»), smoke `mcp`.

5. **Хранение настроек.** Триггер: `installer/install.ps1` (`Encrypt-*`, `Export-Clixml`, `Update-Config`), `app/settings.js`, `mac/install-mac.sh` (`umask`, `chmod 600`, `add`). Что проверить: на Windows пароли только в `settings.xml` через DPAPI (`ConvertFrom-SecureString`), в `config.toml` паролей нет; на Mac `config.toml` с правами 600; `settings.js` по-прежнему зовёт системный `powershell.exe` 5.1, а не PowerShell 7. Откуда: шапка `app/settings.js`, README, smoke `pack` («пароль 1С не лежит открытым текстом»).

6. **Путь объекта не выходит за OData.** Триггер: `safePath`, `baseUrl`, `odataGet`, обработка редиректов. Что проверить: запрещены `..`, `?`, `#`, `://`, обратный слэш; полный адрес принимается только с `/odata/standard.odata/`; редирект следует только на тот же сервер. Откуда: `safePath` в `server/index.js`, `tests/suite.mjs` («попытка выйти за OData заблокирована», «редирект на том же сервере»).

7. **config.toml пользователя.** Триггер: `Remove-OurBlock`, `Update-Config` в `install.ps1`, `awk`-блок и маркеры `BEGIN`/`END` в `install-mac.sh`, парсер в `mac/check.mjs`. Что проверить: чужие строки и таблицы `config.toml` не трогаются; первая копия сохраняется как `config.toml.bak-1c`; повторная установка не плодит второй `[mcp_servers.one-c-odata]`; удаление убирает только наш блок; формат, который пишет `install-mac.sh`, читается `check.mjs` (маркеры, `KEY = "json-строка"`). Откуда: README («ничего больше не трогает»), smoke `pack` (установка, повтор, удаление).

8. **Сборка ZIP.** Триггер: `build.py`, новый файл в `app/`, `server/`, `installer/`, `mac/`, новая зависимость в `package.json`. Что проверить: новый файл попадает в список копирования `build.py` (иначе его нет у пользователя); имена архивов `1c-connector-for-chatgpt.zip` и `1c-connector-for-chatgpt-mac.zip` не меняются (на них ведут ссылки `releases/latest/download/...` в README); `install.ps1` и `README.txt` с BOM и CRLF, `.bat` с CRLF; в архив не попадают настройки, `node_modules` нативные модули и тесты; `install-mac.sh` с правами 755. Откуда: `build.py`, README (ссылки на скачивание), smoke `pack`.

9. **Совместимость PowerShell 5.1 и bash на Mac.** Триггер: правки `install.ps1`, `INSTALL.bat`, `UNINSTALL.bat`, `install-mac.sh`. Что проверить: в `install.ps1` нет синтаксиса PowerShell 7 (`??`, `&&`, `||`, тернарный `?:`); `Assert-OwnDir` стоит перед любым `Remove-Item -Recurse`; `install-mac.sh` с LF (`.gitattributes`: `mac/*.sh text eol=lf`), без bash 4+ (`declare -A`, `${x,,}`), потому что на Mac bash 3.2. Откуда: шапка `build.py` (про PowerShell 5.1 и BOM), `.gitattributes`.
